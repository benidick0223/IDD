Helpful photos for a route's guide page (stops, landmarks, where to board or get off).
Name files <route id>-<number>, for example r12-1.jpg, then reference them with  photos: [{ key: "r12-1", kind: "board", caption: "..." }]  in src/collected-routes.ts.
Supported formats: JPG, JPEG, PNG, WebP, AVIF.
